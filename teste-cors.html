Descobre se o seu domínio consegue conversar com o Apps Script. É o que decide se dá para migrar o CarWay.

Verificando origem…

O que cada teste significa.
O GET confirma que a URL está publicada e acessível.
O POST é o que importa: é assim que o CarWay migrado vai enviar os dados. Ele manda JSON com Content-Type: text/plain de propósito, para evitar o preflight OPTIONS que o Apps Script não sabe responder.
